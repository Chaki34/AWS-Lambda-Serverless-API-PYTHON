# From Traditional Backend Hosting to Serverless Computing – Exploring AWS Lambda & API Gateway

I’m pleased to share my progress on **Module 05: AWS Lambda & Serverless** as part of my cloud computing learning journey with **Codomax**.

For this module, I worked on **CloudAPI – a Serverless REST API**, designed to understand how backend functionality can be executed without managing traditional application servers.

**Technologies explored:**
- AWS Lambda
- Amazon API Gateway (HTTP API)
- Python
- JSON
- Postman

The project demonstrates four API endpoints: API information, a welcome message, a health check, and a POST endpoint for personalized greetings. I also focused on request validation, JSON responses, Lambda testing, and API Gateway–Lambda integration.

This hands-on exercise helped me understand serverless architecture, event-driven execution, API routing, and cloud-based backend deployment.
